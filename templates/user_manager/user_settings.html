Open with SSH

A click on the address opens an SSH session: ssh://username@address:port. Devices without a username or password, and monitoring devices, are shown as plain text.

Open with Winbox

A click on the address opens MikroTik Winbox: winbox://address. Only RouterOS devices offer this, every other device is shown as plain text.

Show a menu (SSH / Winbox)

Moving the mouse over the address opens a menu with both entries. Only the ones the device supports are offered, so a device that is not a RouterOS device keeps the plain SSH link.
